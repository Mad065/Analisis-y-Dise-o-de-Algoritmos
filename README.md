# Análisis y Diseño de Algoritmos

¡Bienvenido a este repositorio de la materia **Análisis y Diseño de Algoritmos**!

Este repositorio está dedicado a almacenar apuntes y las prácticas en código. Aquí exploraremos las técnicas para evaluar la eficiencia, el cálculo de la complejidad computacional y las diferentes estrategias para construir algoritmos óptimos para la resolución de problemas.

---

## 🛠️ Tecnologías y Lenguajes

Durante el desarrollo de este curso, nos enfocaremos casi de manera exclusiva en el siguiente lenguaje para la implementación y prueba de nuestros algoritmos:

* **Lenguaje Principal:** `Python`

---

## 📁 Estructura del Repositorio

El contenido estará organizado de forma sencilla en las siguientes carpetas:

* [`/apuntes`](./apuntes): Notas de clase, demostraciones matemáticas, análisis de complejidad y resúmenes teóricos en formato Markdown (`.md`).
* [`/practicas`](./practicas): Implementación de algoritmos, estructuras de datos y programas de laboratorio.
